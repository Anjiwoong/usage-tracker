# Codex 주간 할당량 전환 설계

## 목적

Codex의 사용량 정책이 5시간 및 1주 이중 할당량에서 1주 할당량으로 변경된 상태를 사용량 추적기에 반영한다. Codex 메뉴바 요약과 상세 메뉴는 주간 사용량만 표시해야 하며, Claude의 5시간·1주 표시 방식에는 영향을 주지 않는다.

## 범위

- Codex API 응답의 `primary` 버킷을 주간 할당량으로 해석한다.
- `CodexUsage`는 주간 사용률과 주간 리셋까지 남은 시간만 보관한다.
- Codex 요약과 상세 메뉴에서 `1주` 사용량 및 날짜 기준 리셋 안내만 표시한다.
- Codex 파서와 팝오버 테스트를 새 데이터 의미에 맞게 갱신한다.

## 제외 범위

- 이전 5시간/1주 이중 버킷 API에 대한 호환 레이어를 만들지 않는다.
- Cursor와 Claude의 데이터 모델 및 표시는 변경하지 않는다.
- 데이터 조회 주기, 알림 기준, 메뉴 스타일은 변경하지 않는다.

## 설계

### 데이터 흐름

`CodexFetcher.parse_codex_rate_limits`는 `rateLimits.primary.usedPercent`와 `resetsAt`을 Codex의 주간 사용량 및 리셋 시각으로 변환한다. `secondary`는 읽거나 저장하지 않는다. 오류 경로도 동일한 주간 필드를 0으로 채워 일관된 `CodexUsage` 객체를 반환한다.

### 표시

메뉴바의 Codex 요약은 `1주` 라벨과 주간 사용률을 사용한다. 상세 Codex 섹션은 다음 두 줄만 표시한다.

1. `1주` 사용률과 진행 바
2. 주간 리셋까지 남은 기간 및 리셋 날짜

기존 5시간 사용률과 시각 기준 리셋 안내는 Codex 섹션에서 제거한다. Claude 섹션은 기존 두 기간을 계속 표시한다.

### 오류 처리

Codex CLI 부재, 인증 실패, 일반 조회 실패 시에도 `CodexUsage`의 주간 필드는 0으로 초기화하고 기존 오류 메시지 표시를 유지한다.

### 테스트

- Codex 파서가 `primary`를 주간 사용량으로 반환하는지 검증한다.
- Codex 메뉴바 요약이 `1주` 라벨을 사용하는지 검증한다.
- Codex 상세 메뉴가 주간 사용량과 날짜 기준 리셋 안내만 포함하며 `5시간` 항목은 포함하지 않는지 검증한다.
- Claude의 기존 5시간·1주 표시는 회귀하지 않는지 기존 테스트로 확인한다.

## 완료 기준

- Codex 화면에 5시간 할당량이 표시되지 않는다.
- Codex 화면에 주간 사용량과 주간 리셋 날짜가 표시된다.
- 단위 테스트 전체가 통과한다.
